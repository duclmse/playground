Yes. I’d make the backend layer a proper **target-language-independent codegen
API**, then implement Rust, C++, and JavaScript against the same IR.

One important correction to the previous version: the backend should **not
independently rediscover parser decisions**. The frontend should produce a
parser IR containing alternatives and lookahead information, and all three
backends simply render that IR.

## 1\. Backend architecture

I recommend this structure:

```
src/
├── backend/
│   ├── mod.rs
│   ├── rust.rs
│   ├── cpp.rs
│   └── javascript.rs
│
├── ir.rs
├── analysis.rs
├── lower.rs
└── generate.rs
```

The public API becomes:

```rust
pub enum Target {
    Rust,
    Cpp,
    JavaScript,
}
```

and:

```rust
pub fn generate(grammar: &Grammar, target: Target) -> Result<String, Error>
```

Internally:

```
      Grammar
          │
          ▼
      EBNF AST
          │
          ▼
      Lowered IR
          │
          ▼
      Parser Analysis
          │
          ▼
      Parser IR
          │
┌─────────┼─────────┐
▼         ▼         ▼
Rust      C++       JS
backend   backend   backend
```

# 2\. Backend trait

Replace `src/backend/mod.rs` with:

```
use crate::{
    analysis::Analysis,
    error::Error,
    ir::GrammarIr,
};

pub mod cpp;
pub mod javascript;
pub mod rust;

pub trait Backend {
    type Output;

    fn generate(
        &self,
        grammar: &GrammarIr,
        analysis: &Analysis,
    ) -> Result<Self::Output, Error>;
}

#[derive(Debug, Clone, Copy)]
pub enum Target {
    Rust,
    Cpp,
    JavaScript,
}

pub fn backend_for(target: Target) -> Box<dyn Backend<Output = String>> {
    match target {
        Target::Rust => Box::new(rust::RustBackend),
        Target::Cpp => Box::new(cpp::CppBackend),
        Target::JavaScript => Box::new(javascript::JavaScriptBackend),
    }
}
```

Then `generate.rs` can become:

```
use crate::{
    analysis::analyze,
    backend::{backend_for, Target},
    error::Error,
    grammar::ast::Grammar,
    lower::lower,
};

pub fn generate(
    grammar: &Grammar,
    target: Target,
) -> Result<String, Error> {
    let ir = lower(grammar)?;
    let analysis = analyze(&ir)?;

    backend_for(target).generate(&ir, &analysis)
}
```

Usage:

```
let grammar = parse_grammar(source)?;

let rust = generate(&grammar, Target::Rust)?;
let cpp = generate(&grammar, Target::Cpp)?;
let js = generate(&grammar, Target::JavaScript)?;
```

# 3\. Make the generated runtime consistent

All three backends should expose approximately the same generated API.

For example:

```
Lexer
  tokenize(input)

Parser
  new(tokens)
  parse()
```

And tokens have:

```
kind
lexeme
start
end
```

That gives users a consistent generated interface regardless of target.

# 4\. Rust backend

`src/backend/rust.rs`:

```
use std::fmt::Write;

use crate::{
    analysis::Analysis,
    backend::Backend,
    error::Error,
    ir::*,
};

pub struct RustBackend;

impl Backend for RustBackend {
    type Output = String;

    fn generate(
        &self,
        grammar: &GrammarIr,
        analysis: &Analysis,
    ) -> Result<String, Error> {
        let mut out = String::new();

        emit_prelude(&mut out);
        emit_tokens(&mut out, grammar);
        emit_lexer(&mut out, grammar);
        emit_parser(&mut out, grammar, analysis)?;

        Ok(out)
    }
}

fn emit_prelude(out: &mut String) {
    writeln!(
        out,
        r#"// Generated by ebnfgen.

use regex::Regex;

#[derive(Debug, Clone)]
pub struct Span {{
    pub start: usize,
    pub end: usize,
}}

#[derive(Debug, Clone)]
pub struct Token {{
    pub kind: TokenKind,
    pub lexeme: String,
    pub span: Span,
}}
"#
    )
    .unwrap();
}

fn emit_tokens(out: &mut String, grammar: &GrammarIr) {
    writeln!(out, "#[derive(Debug, Clone, PartialEq, Eq)]").unwrap();
    writeln!(out, "pub enum TokenKind {{").unwrap();

    for token in &grammar.tokens {
        if !token.skip {
            writeln!(out, "    {},", token.name).unwrap();
        }
    }

    for rule in &grammar.rules {
        for alt in &rule.alternatives {
            for symbol in &alt.symbols {
                if let SymbolIr::Terminal(value) = symbol {
                    writeln!(
                        out,
                        "    {},",
                        literal_variant(value)
                    )
                    .unwrap();
                }
            }
        }
    }

    writeln!(out, "    Eof,").unwrap();
    writeln!(out, "}}\n").unwrap();
}

fn emit_lexer(
    out: &mut String,
    grammar: &GrammarIr,
) {
    writeln!(
        out,
        r#"pub struct Lexer {{
    rules: Vec<(Regex, TokenKind, bool)>,
}}

impl Lexer {{
    pub fn new() -> Result<Self, regex::Error> {{
        let mut rules = Vec::new();
"#
    )
    .unwrap();

    for token in &grammar.tokens {
        writeln!(
            out,
            "        rules.push((Regex::new(r#\"^(?:{})\"#)?, TokenKind::{}, {}));",
            token.pattern,
            token.name,
            token.skip
        )
        .unwrap();
    }

    writeln!(
        out,
        r#"        Ok(Self {{ rules }})
    }}

    pub fn tokenize(
        &self,
        input: &str,
    ) -> Result<Vec<Token>, String> {{
        let mut tokens = Vec::new();
        let mut pos = 0;

        while pos < input.len() {{
            let rest = &input[pos..];
            let mut matched = false;

            for (regex, kind, skip) in &self.rules {{
                if let Some(m) = regex.find(rest) {{
                    if m.start() != 0 {{
                        continue;
                    }}

                    let text = m.as_str();

                    if text.is_empty() {{
                        return Err(format!(
                            "lexer rule matched empty input at {{}}",
                            pos
                        ));
                    }}

                    let end = pos + text.len();

                    if !*skip {{
                        tokens.push(Token {{
                            kind: kind.clone(),
                            lexeme: text.to_string(),
                            span: Span {{
                                start: pos,
                                end,
                            }},
                        }});
                    }}

                    pos = end;
                    matched = true;
                    break;
                }}
            }}

            if !matched {{
                return Err(format!(
                    "unexpected input at byte {{}}",
                    pos
                ));
            }}
        }}

        tokens.push(Token {{
            kind: TokenKind::Eof,
            lexeme: String::new(),
            span: Span {{
                start: pos,
                end: pos,
            }},
        }});

        Ok(tokens)
    }}
}}
"#
    )
    .unwrap();
}

fn emit_parser(
    out: &mut String,
    grammar: &GrammarIr,
    analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        r#"pub struct Parser {{
    tokens: Vec<Token>,
    pos: usize,
}}

impl Parser {{
    pub fn new(tokens: Vec<Token>) -> Self {{
        Self {{ tokens, pos: 0 }}
    }}

    fn peek(&self) -> &TokenKind {{
        &self.tokens[self.pos].kind
    }}

    fn consume(&mut self) -> Token {{
        let token = self.tokens[self.pos].clone();
        self.pos += 1;
        token
    }}

    fn expect(
        &mut self,
        kind: TokenKind,
    ) -> Result<Token, String> {{
        if *self.peek() == kind {{
            Ok(self.consume())
        }} else {{
            Err(format!(
                "expected {{:?}}, got {{:?}}",
                kind,
                self.peek()
            ))
        }}
    }}
"#
    )
    .unwrap();

    for rule in &grammar.rules {
        emit_rust_rule(out, rule, analysis)?;
    }

    writeln!(out, "}}\n").unwrap();

    Ok(())
}

fn emit_rust_rule(
    out: &mut String,
    rule: &RuleIr,
    analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        "    pub fn parse_{}(&mut self) -> Result<(), String> {{",
        rule.name
    )
    .unwrap();

    if rule.alternatives.len() == 1 {
        emit_sequence(out, &rule.alternatives[0])?;
    } else {
        writeln!(out, "        match self.peek() {{").unwrap();

        for alt in &rule.alternatives {
            if let Some(first) = first_symbol(alt, analysis) {
                writeln!(
                    out,
                    "            {} => {{",
                    rust_pattern(first)
                )
                .unwrap();

                emit_sequence(out, alt)?;

                writeln!(out, "            }}").unwrap();
            }
        }

        writeln!(
            out,
            "            _ => return Err(format!(\
                \"unexpected token in {}: {{:?}}\", \
                self.peek()\
            )),",
            rule.name
        )
        .unwrap();

        writeln!(out, "        }}").unwrap();
    }

    writeln!(out, "        Ok(())").unwrap();
    writeln!(out, "    }}\n").unwrap();

    Ok(())
}

fn emit_sequence(
    out: &mut String,
    alt: &AlternativeIr,
) -> Result<(), Error> {
    for symbol in &alt.symbols {
        match symbol {
            SymbolIr::Terminal(value) => {
                writeln!(
                    out,
                    "                self.expect(TokenKind::{})?;",
                    literal_variant(value)
                )
                .unwrap();
            }

            SymbolIr::Token(name) => {
                writeln!(
                    out,
                    "                self.expect(TokenKind::{})?;",
                    name
                )
                .unwrap();
            }

            SymbolIr::Rule(name) => {
                writeln!(
                    out,
                    "                self.parse_{}()?;",
                    name
                )
                .unwrap();
            }
        }
    }

    Ok(())
}

fn first_symbol<'a>(
    alt: &'a AlternativeIr,
    analysis: &Analysis,
) -> Option<&'a SymbolIr> {
    alt.symbols.first()
}

fn rust_pattern(symbol: &SymbolIr) -> String {
    match symbol {
        SymbolIr::Terminal(value) => {
            format!("TokenKind::{}", literal_variant(value))
        }

        SymbolIr::Token(name) => {
            format!("TokenKind::{}", name)
        }

        SymbolIr::Rule(name) => {
            format!("_ /* FIRST({}) */", name)
        }
    }
}

pub fn literal_variant(value: &str) -> String {
    let mut result = String::from("Lit_");

    for c in value.chars() {
        if c.is_ascii_alphanumeric() {
            result.push(c);
        } else {
            result.push_str(&format!("U{:04X}", c as u32));
        }
    }

    result
}
```

The important point here is that **the same `GrammarIr` goes in**. Nothing in
the grammar frontend knows that Rust exists.

# 5\. C++ backend

For C++, I'd generate C++17.

`src/backend/cpp.rs`:

```
use std::fmt::Write;

use crate::{
    analysis::Analysis,
    backend::Backend,
    error::Error,
    ir::*,
};

use super::rust::literal_variant;

pub struct CppBackend;

impl Backend for CppBackend {
    type Output = String;

    fn generate(
        &self,
        grammar: &GrammarIr,
        analysis: &Analysis,
    ) -> Result<String, Error> {
        let mut out = String::new();

        emit_header(&mut out);
        emit_tokens(&mut out, grammar);
        emit_lexer(&mut out, grammar);
        emit_parser(&mut out, grammar, analysis)?;

        Ok(out)
    }
}

fn emit_header(out: &mut String) {
    writeln!(
        out,
        r#"#include <regex>
#include <string>
#include <string_view>
#include <vector>
#include <stdexcept>
#include <cstddef>
#include <utility>

namespace generated {{

struct Span {{
    std::size_t start;
    std::size_t end;
}};

struct Token {{
    TokenKind kind;
    std::string lexeme;
    Span span;
}};
"#
    )
    .unwrap();
}

fn emit_tokens(
    out: &mut String,
    grammar: &GrammarIr,
) {
    writeln!(out, "enum class TokenKind {{").unwrap();

    for token in &grammar.tokens {
        if !token.skip {
            writeln!(
                out,
                "    {},",
                token.name
            )
            .unwrap();
        }
    }

    for rule in &grammar.rules {
        for alt in &rule.alternatives {
            for symbol in &alt.symbols {
                if let SymbolIr::Terminal(value) = symbol {
                    writeln!(
                        out,
                        "    {},",
                        literal_variant(value)
                    )
                    .unwrap();
                }
            }
        }
    }

    writeln!(out, "    Eof").unwrap();
    writeln!(out, "}};\n").unwrap();
}

fn emit_lexer(
    out: &mut String,
    grammar: &GrammarIr,
) {
    writeln!(
        out,
        r#"class Lexer {{
    struct Rule {{
        std::regex regex;
        TokenKind kind;
        bool skip;
    }};

    std::vector<Rule> rules;

public:
    Lexer() {{
"#
    )
    .unwrap();

    for token in &grammar.tokens {
        writeln!(
            out,
            "        rules.push_back({{std::regex(R\"(^(?:{}) )\"), TokenKind::{}, {}}});",
            token.pattern,
            token.name,
            token.skip
        )
        .unwrap();
    }

    writeln!(
        out,
        r#"    }}

    std::vector<Token> tokenize(
        std::string_view input
    ) const {{
        std::vector<Token> result;

        std::size_t pos = 0;

        while (pos < input.size()) {{
            bool matched = false;

            std::string rest(input.substr(pos));

            for (const auto& rule : rules) {{
                std::smatch match;

                if (!std::regex_search(
                    rest,
                    match,
                    rule.regex
                )) {{
                    continue;
                }}

                if (match.position() != 0) {{
                    continue;
                }}

                std::string text = match.str();

                if (text.empty()) {{
                    throw std::runtime_error(
                        "lexer matched empty input"
                    );
                }}

                std::size_t end = pos + text.size();

                if (!rule.skip) {{
                    result.push_back(Token{{
                        rule.kind,
                        text,
                        Span{{pos, end}}
                    }});
                }}

                pos = end;
                matched = true;
                break;
            }}

            if (!matched) {{
                throw std::runtime_error(
                    "unexpected input"
                );
            }}
        }}

        result.push_back(Token{{
            TokenKind::Eof,
            "",
            Span{{pos, pos}}
        }});

        return result;
    }}
}};
"#
    )
    .unwrap();
}

fn emit_parser(
    out: &mut String,
    grammar: &GrammarIr,
    analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        r#"class Parser {{
    std::vector<Token> tokens;
    std::size_t pos = 0;

public:
    explicit Parser(std::vector<Token> tokens)
        : tokens(std::move(tokens)) {{}}

    const Token& peek() const {{
        return tokens[pos];
    }}

    Token consume() {{
        return tokens[pos++];
    }}

    Token expect(TokenKind kind) {{
        if (peek().kind != kind) {{
            throw std::runtime_error(
                "unexpected token"
            );
        }}

        return consume();
    }}
"#
    )
    .unwrap();

    for rule in &grammar.rules {
        emit_rule(out, rule, analysis)?;
    }

    writeln!(out, "}};\n").unwrap();
    writeln!(out, "}} // namespace generated").unwrap();

    Ok(())
}

fn emit_rule(
    out: &mut String,
    rule: &RuleIr,
    _analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        "    void parse_{}() {{",
        rule.name
    )
    .unwrap();

    if rule.alternatives.len() == 1 {
        emit_sequence(out, &rule.alternatives[0]);
    } else {
        writeln!(
            out,
            "        switch (peek().kind) {{"
        )
        .unwrap();

        for alt in &rule.alternatives {
            if let Some(first) = alt.symbols.first() {
                writeln!(
                    out,
                    "            case {}: {{",
                    cpp_symbol(first)
                )
                .unwrap();

                emit_sequence(out, alt);

                writeln!(out, "                break;").unwrap();
                writeln!(out, "            }}").unwrap();
            }
        }

        writeln!(
            out,
            "            default:
                throw std::runtime_error(
                    \"no parser alternative matched\"
                );"
        )
        .unwrap();

        writeln!(out, "        }}").unwrap();
    }

    writeln!(out, "    }}\n").unwrap();

    Ok(())
}

fn emit_sequence(
    out: &mut String,
    alt: &AlternativeIr,
) {
    for symbol in &alt.symbols {
        match symbol {
            SymbolIr::Terminal(value) => {
                writeln!(
                    out,
                    "                expect(TokenKind::{});",
                    literal_variant(value)
                )
                .unwrap();
            }

            SymbolIr::Token(name) => {
                writeln!(
                    out,
                    "                expect(TokenKind::{});",
                    name
                )
                .unwrap();
            }

            SymbolIr::Rule(name) => {
                writeln!(
                    out,
                    "                parse_{}();",
                    name
                )
                .unwrap();
            }
        }
    }
}

fn cpp_symbol(symbol: &SymbolIr) -> String {
    match symbol {
        SymbolIr::Terminal(value) => {
            format!(
                "TokenKind::{}",
                literal_variant(value)
            )
        }

        SymbolIr::Token(name) => {
            format!("TokenKind::{}", name)
        }

        SymbolIr::Rule(_) => {
            // The final version should use FIRST sets.
            "TokenKind::Eof".into()
        }
    }
}
```

# 6\. JavaScript backend

JavaScript is particularly nice because its regex engine is already available.

`src/backend/javascript.rs`:

```
use std::fmt::Write;

use crate::{
    analysis::Analysis,
    backend::Backend,
    error::Error,
    ir::*,
};

use super::rust::literal_variant;

pub struct JavaScriptBackend;

impl Backend for JavaScriptBackend {
    type Output = String;

    fn generate(
        &self,
        grammar: &GrammarIr,
        analysis: &Analysis,
    ) -> Result<String, Error> {
        let mut out = String::new();

        emit_header(&mut out);
        emit_tokens(&mut out, grammar);
        emit_lexer(&mut out, grammar);
        emit_parser(&mut out, grammar, analysis)?;

        Ok(out)
    }
}

fn emit_header(out: &mut String) {
    writeln!(
        out,
        r#"// Generated by ebnfgen.

export class Token {{
    constructor(kind, lexeme, start, end) {{
        this.kind = kind;
        this.lexeme = lexeme;
        this.start = start;
        this.end = end;
    }}
}}
"#
    )
    .unwrap();
}

fn emit_tokens(
    out: &mut String,
    grammar: &GrammarIr,
) {
    writeln!(
        out,
        "export const TokenKind = Object.freeze({{"
    )
    .unwrap();

    for token in &grammar.tokens {
        if !token.skip {
            writeln!(
                out,
                "    {}: \"{}\",",
                token.name,
                token.name
            )
            .unwrap();
        }
    }

    for rule in &grammar.rules {
        for alt in &rule.alternatives {
            for symbol in &alt.symbols {
                if let SymbolIr::Terminal(value) = symbol {
                    let variant = literal_variant(value);

                    writeln!(
                        out,
                        "    {}: \"{}\",",
                        variant,
                        variant
                    )
                    .unwrap();
                }
            }
        }
    }

    writeln!(
        out,
        "    Eof: \"Eof\""
    )
    .unwrap();

    writeln!(out, "}});\n").unwrap();
}

fn emit_lexer(
    out: &mut String,
    grammar: &GrammarIr,
) {
    writeln!(
        out,
        r#"export class Lexer {{
    constructor() {{
        this.rules = [
"#
    )
    .unwrap();

    for token in &grammar.tokens {
        writeln!(
            out,
            "            {{ regex: /^(?:{})/, kind: TokenKind.{}, skip: {} }},",
            token.pattern,
            token.name,
            token.skip
        )
        .unwrap();
    }

    writeln!(
        out,
        r#"        ];
    }}

    tokenize(input) {{
        const tokens = [];
        let pos = 0;

        while (pos < input.length) {{
            const rest = input.slice(pos);
            let matched = false;

            for (const rule of this.rules) {{
                const match = rule.regex.exec(rest);

                if (!match) {{
                    continue;
                }}

                const text = match[0];

                if (text.length === 0) {{
                    throw new Error(
                        `lexer matched empty input at ${{pos}}`
                    );
                }}

                const end = pos + text.length;

                if (!rule.skip) {{
                    tokens.push(
                        new Token(
                            rule.kind,
                            text,
                            pos,
                            end
                        )
                    );
                }}

                pos = end;
                matched = true;
                break;
            }}

            if (!matched) {{
                throw new Error(
                    `unexpected input at ${{pos}}`
                );
            }}
        }}

        tokens.push(
            new Token(
                TokenKind.Eof,
                "",
                pos,
                pos
            )
        );

        return tokens;
    }}
}}
"#
    )
    .unwrap();
}

fn emit_parser(
    out: &mut String,
    grammar: &GrammarIr,
    analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        r#"export class Parser {{
    constructor(tokens) {{
        this.tokens = tokens;
        this.pos = 0;
    }}

    peek() {{
        return this.tokens[this.pos];
    }}

    consume() {{
        return this.tokens[this.pos++];
    }}

    expect(kind) {{
        if (this.peek().kind !== kind) {{
            throw new Error(
                `expected ${{kind}}, got ${{this.peek().kind}}`
            );
        }}

        return this.consume();
    }}
"#
    )
    .unwrap();

    for rule in &grammar.rules {
        emit_rule(out, rule, analysis)?;
    }

    writeln!(out, "}}\n").unwrap();

    Ok(())
}

fn emit_rule(
    out: &mut String,
    rule: &RuleIr,
    _analysis: &Analysis,
) -> Result<(), Error> {
    writeln!(
        out,
        "    parse_{}() {{",
        rule.name
    )
    .unwrap();

    if rule.alternatives.len() == 1 {
        emit_sequence(out, &rule.alternatives[0]);
    } else {
        writeln!(
            out,
            "        switch (this.peek().kind) {{"
        )
        .unwrap();

        for alt in &rule.alternatives {
            if let Some(first) = alt.symbols.first() {
                writeln!(
                    out,
                    "            case {}:",
                    js_symbol(first)
                )
                .unwrap();

                emit_sequence(out, alt);

                writeln!(out, "                break;").unwrap();
            }
        }

        writeln!(
            out,
            r#"            default:
                throw new Error(
                    `no alternative matched in {}`
                );"#,
            rule.name
        )
        .unwrap();

        writeln!(out, "        }}").unwrap();
    }

    writeln!(out, "    }}\n").unwrap();

    Ok(())
}

fn emit_sequence(
    out: &mut String,
    alt: &AlternativeIr,
) {
    for symbol in &alt.symbols {
        match symbol {
            SymbolIr::Terminal(value) => {
                writeln!(
                    out,
                    "                this.expect(TokenKind.{});",
                    literal_variant(value)
                )
                .unwrap();
            }

            SymbolIr::Token(name) => {
                writeln!(
                    out,
                    "                this.expect(TokenKind.{});",
                    name
                )
                .unwrap();
            }

            SymbolIr::Rule(name) => {
                writeln!(
                    out,
                    "                this.parse_{}();",
                    name
                )
                .unwrap();
            }
        }
    }
}

fn js_symbol(symbol: &SymbolIr) -> String {
    match symbol {
        SymbolIr::Terminal(value) => {
            format!(
                "TokenKind.{}",
                literal_variant(value)
            )
        }

        SymbolIr::Token(name) => {
            format!("TokenKind.{}", name)
        }

        SymbolIr::Rule(_) => {
            "TokenKind.Eof".into()
        }
    }
}
```

# 7\. CLI

I'd also add a CLI now because it makes the generator much easier to test.

Add to `Cargo.toml`:

```
[dependencies]
regex = "1"
thiserror = "2"
clap = { version = "4", features = ["derive"] }
```

Then:

```
use clap::{Parser, ValueEnum};
use std::fs;

use ebnfgen::{
    backend::Target,
    generate,
    grammar::parser::parse_grammar,
};

#[derive(Parser)]
struct Args {
    grammar: String,

    #[arg(short, long, value_enum)]
    target: TargetArg,

    #[arg(short, long)]
    output: String,
}

#[derive(Clone, ValueEnum)]
enum TargetArg {
    Rust,
    Cpp,
    Javascript,
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let args = Args::parse();

    let source = fs::read_to_string(&args.grammar)?;
    let grammar = parse_grammar(&source)?;

    let target = match args.target {
        TargetArg::Rust => Target::Rust,
        TargetArg::Cpp => Target::Cpp,
        TargetArg::Javascript => Target::JavaScript,
    };

    let generated = generate(&grammar, target)?;

    fs::write(&args.output, generated)?;

    Ok(())
}
```

Now:

```
cargo run -- language.ebnf \
    --target rust \
    --output parser.rs
```

or:

```
cargo run -- language.ebnf \
    --target cpp \
    --output parser.cpp
```

or:

```
cargo run -- language.ebnf \
    --target javascript \
    --output parser.js
```

# 8\. One architectural change I strongly recommend

Before adding more features, I'd change the current parser generation from:

```
Rule
 └── Alternative
      └── Symbol
```

directly into code to:

```
GrammarIr
    │
    ▼
ParserIr
    │
    ├── ParseSequence
    ├── ParseChoice
    ├── ParseOptional
    ├── ParseRepeat
    ├── Consume
    └── Call
```

For example:

```
pub enum ParseOp {
    Consume(Terminal),
    Call(RuleId),

    Sequence(Vec<ParseOp>),

    Choice {
        alternatives: Vec<ParseAlternative>,
    },

    Optional(Box<ParseOp>),

    Repeat(Box<ParseOp>),
}

pub struct ParseAlternative {
    pub lookahead: Vec<Terminal>,
    pub operations: Vec<ParseOp>,
}
```

Then a grammar like:

```
factor =
      NUMBER
    | IDENTIFIER
    | "(" expression ")"
    ;
```

becomes:

```
Choice
├── lookahead: NUMBER
│   └── Consume(NUMBER)
│
├── lookahead: IDENTIFIER
│   └── Consume(IDENTIFIER)
│
└── lookahead: "("
    ├── Consume("(")
    ├── Call(expression)
    └── Consume(")")
```

Now the backend implementations become dramatically simpler:

```
ParserIr
    │
    ├── RustBackend
    │     └── emit_rust(ParseOp)
    │
    ├── CppBackend
    │     └── emit_cpp(ParseOp)
    │
    └── JavaScriptBackend
          └── emit_js(ParseOp)
```

That's the point where this starts becoming a **real multi-target parser
generator** rather than three separate code generators.

It also gives us a clean place to add **AST construction actions** later:

```
expression =
    left=term "+" right=term
    -> Binary(left, right)
;
```

and eventually:

```
EBNF
 ↓
Grammar AST
 ↓
Normalized grammar
 ↓
FIRST/FOLLOW
 ↓
Parser IR
 ↓
┌─────────┬─────────┬──────────────┐
│ Rust    │ C++     │ JavaScript   │
└─────────┴─────────┴──────────────┘
```

That is the architecture I'd use going forward.
